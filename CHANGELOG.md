- `--frontend` wins over the standard layout of `scaffold.toml` (bug: the blueprint layout was returned before the choice was read, so `--frontend board-wip` showed `board`). New `steps.rs`; the help names the option. `fs-components` re-pinned to rev 9cea35b0 (branch `unreviewed/replay-s3`: replay S2 + S3) in all crates; only `fs-forms-run` asks for the feature `play`.
